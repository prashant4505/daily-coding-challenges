# Daily Coding Challenges

A collection of coding challenges and problem-solving exercises solved using PHP.

This repository serves as a personal coding journal where I practice algorithms, logical reasoning, and common interview questions. The goal is to improve problem-solving skills through consistent hands-on coding and clean, readable solutions.

## About

As a developer, continuous learning is essential. This repository contains solutions to various programming challenges ranging from basic logic-building exercises to more advanced algorithmic problems.

Each solution is written with a focus on:

* Readability
* Simplicity
* Maintainability
* Practical problem-solving approaches

## Topics Covered

* String Manipulation
* Arrays
* Algorithms
* Data Structures
* Mathematical Problems
* Pattern Problems
* Logical Reasoning
* Interview Questions
* PHP Fundamentals

## Getting Started

Clone the repository:

```bash
git clone https://github.com/prashant4505/daily-coding-challenges.git
```

Move into the project directory:

```bash
cd daily-coding-challenges
```

Run any challenge file:

```bash
php 01_first_non_repeating_character.php
```
